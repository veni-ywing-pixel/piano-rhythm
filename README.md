# ピアノリズム

電子ピアノ（USB-MIDI）で弾く、ノーツが降ってくるリズムゲームです。タブレットの Chrome で動きます。

## 遊び方

1. 電子ピアノの「USB TO HOST」端子とタブレットを USB ケーブルでつなぐ
2. タブレットの **Chrome** でこのリポジトリの GitHub Pages の URL を開く
3. 「ピアノに接続する」を押して MIDI の使用を許可する
4. サンプル曲を選ぶか、MIDI ファイル（.mid）を開いてスタート

ピアノがなくても、画面下の鍵盤をタッチして遊べます。

## 主な機能

- PERFECT / GREAT / GOOD / MISS の判定、ミスタッチ、コンボ、スコア
- 練習モード（正しい鍵盤を弾くまで止まって待つ）
- 再生速度 25〜150%、パートごとに「弾く / 自動 / オフ」（右手だけ練習など）
- 1パートの曲を真ん中のドで右手・左手に分割
- タイミング補正（結果画面の平均ずれからワンタップで補正）
- 一時停止中に好きな位置へ移動
- 区間ループ（苦手なところだけをくり返す。区間は曲ごとに保存）と、始める前の4拍のカウントイン
- だんだん速く（区間ループで合格したら、次の回を少し速くする。遅めから目標の速さまで）

## 動作環境

- Chrome（Android 6.0 以降のタブレット、または PC）
- HTTPS のページとして開く必要があります（Web MIDI の制約）。埋め込み表示（iframe）では MIDI が使えません
